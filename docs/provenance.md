# Provenance, attribution and distribution

This repository is prepared from the supplied VEX Shadow Audit 1.1.0 implementation. The original package was an evaluation-only distribution with an unnamed-author copyright notice. That notice is retained in NOTICE. The original copyright holder has confirmed ownership and expressly authorized publication of the derivative under MIT.

The runtime implementation, synthetic fixtures and original regression suite are project artifacts. External Trivy, OpenVEX and PURL implementations were inspected as technical references; no upstream implementation files or patches are bundled. Standard-library modules are used through the Python interpreter and are not vendored.

The portfolio preparation changes consist of English documentation, CI configuration, explicit synthetic example identifiers, and a strengthened contradiction test. The source is not represented as entirely written by hand, and no individual's authorship or execution history is inferred from repository ownership.

Validation records describe checks against the supplied artifacts and this candidate, including a separate critical review. They do not attribute discoveries, local commands or upstream contributions to the repository holder. Public upstream work remains attributed through the original issue, PR and source links.

Historical ZIPs, original-source duplicates, private audit histories, commercial reviews, local paths and raw execution logs are excluded from this repository. Relevant technical findings and reproducible commands are summarized in validation.md; the exclusion does not turn failed checks into successful ones.

MIT grants broad redistribution and use rights. Preparing a noncommercial portfolio is the project's purpose, not an additional noncommercial restriction on that license. No endorsement, official integration, new security vulnerability or commercial service is claimed.
